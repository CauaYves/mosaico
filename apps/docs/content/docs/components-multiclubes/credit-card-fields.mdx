Os quatro campos de um cartão: número, validade, CVV e nome impresso. As máscaras entram enquanto a pessoa digita, e cada campo mostra o seu erro ao perder o foco.

## Installation

<Installation name="credit-card-fields" />

Instala também `lib/mosaico/credit-card`, com as máscaras, a bandeira e a validação.

## Usage

```tsx
import { CreditCardFields } from "@multiclubes/ui/components/credit-card-fields"
import { EMPTY_CREDIT_CARD } from "@multiclubes/ui/lib/credit-card"
```

```tsx
const [card, setCard] = React.useState(EMPTY_CREDIT_CARD)

<CreditCardFields value={card} onValueChange={setCard} />
```

O componente é controlado e não envia nada: o formulário em volta decide o que fazer com o valor.

## No envio

No envio, passe `showErrors` para mostrar o erro de todos os campos e leve o foco ao primeiro: `validateCreditCard` devolve os erros, e cada campo traz `data-field` com o seu nome. O exemplo do topo faz isso.

```tsx
const errors = validateCreditCard(card)
const first = CREDIT_CARD_FIELDS.find((field) => errors[field])
form.querySelector(`[data-field="${first}"]`)?.focus()
```

## Bandeira e tamanho

A bandeira aparece no campo do número quando os primeiros dígitos a revelam: Visa, Mastercard, Elo, Amex, Hipercard e Diners. Por padrão é o nome dela; `renderBrand` troca pelo desenho que a aplicação tiver. `size="lg"` deixa os campos com 48px de altura, para telas de pagamento no celular.

## Como funciona

- **Sem lista de bandeiras:** se a aplicação aceita todas, listar algumas sugere que as outras não passam. A bandeira do cartão aparece no campo, e só a dela.
- **CVV:** três dígitos, quatro no Amex. A dica do campo e o limite mudam com a bandeira, e o código já digitado é cortado se ela mudar.
- **Validade:** aceita o que o preenchimento automático e a colagem trazem, como `12/2045`.
- **Número:** conferido pelo dígito verificador. Uma bandeira que o campo não reconhece continua válida.
- **Dado sensível:** o número completo vai para o provedor de pagamento, que devolve um token. Não o envie ao seu servidor nem o registre em log.
- **Teclado numérico:** número, validade e CVV abrem o teclado de números no celular, e todos os campos avisam o navegador de que são de cartão (`autocomplete`).

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `value` | `CreditCardValue` | — | Os quatro campos, já com a máscara. |
| `onValueChange` | `(value: CreditCardValue) => void` | — | Chamado a cada digitação, com o valor já mascarado. |
| `showErrors` | `boolean` | `false` | Mostra o erro de todos os campos, e não só dos que perderam o foco. |
| `renderBrand` | `(brand: CreditCardBrand) => ReactNode` | — | O desenho da bandeira reconhecida. Sem isso, o nome dela. |
| `size` | `"default" \| "lg"` | `"default"` | `lg` deixa os campos com 48px de altura. |
| `disabled` | `boolean` | `false` | Desabilita os quatro campos. |

As demais props vão para o `FieldGroup`.

### lib/credit-card

| Função | O que faz |
| --- | --- |
| `validateCreditCard(value)` | Os erros de todos os campos; um objeto vazio quer dizer que pode enviar. |
| `validateCreditCardField(field, value)` | O erro de um campo. |
| `creditCardBrand(number)` | A bandeira que os primeiros dígitos revelam. |
| `cvcLength(number)` | O tamanho do CVV para a bandeira do número. |
| `maskCreditCardField(field, value, number)` | A máscara de um campo. |
